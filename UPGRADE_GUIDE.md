# 🚀 Инструкция по обновлению до версии с ML интеграцией

## 📋 Что нового

### ✨ Основные изменения
- **🤖 ML классификация заявок** - автоматическая категоризация с точностью 60-80%
- **👥 Ролевой доступ** - ограничения интерфейса для обычных пользователей
- **📊 Админские инструменты** - управление ML моделями и статистика

- `bot_model` - основная KNeighborsClassifier с 145 категориями

- Кэширование предсказаний для производительности

## 🔄 Процесс обновления

### 1. Обновление кода
```bash
cd okypbot
git pull origin feature/ml-classification
```

### 2. Обновление зависимостей
```bash
pip install -r requirements.txt

# Проверка новых зависимостей
pip list | grep -E "(sentence-transformers|scikit-learn)"
```

### 3. Настройка переменных окружения
Добавьте в `.env`:
```bash
# ID администраторов для доступа к ML функциям (через запятую)
ADMIN_IDS=413129274,123456789

# Существующие переменные остаются без изменений
BOT_TOKEN=your_bot_token
OKDESK_API_TOKEN=your_api_token
OKDESK_BASE_URL=https://your-domain.okdesk.ru
```

### 4. Проверка структуры файлов
```bash
# Убедитесь, что присутствуют новые файлы
ls -la bot_model/
ls -la ml/bot_model_adapter.py
ls -la handlers/bot_model_handlers.py
```

### 5. Перезапуск сервиса

#### Docker (рекомендуется)
```bash
# Остановка старых контейнеров
docker-compose down

# Пересборка с новыми зависимостями  
docker-compose up --build -d

# Проверка логов
docker-compose logs -f bot
```

#### Ручной запуск
```bash
# Остановка старого процесса
pkill -f "python main.py"

# Запуск с новой версией
python main.py
```
