## 🔧 Как использовать

### Для клиентов (как Кирилл):
1. Создают заявку через Telegram бота
2. Получают уведомления о новых комментариях от специалистов
3. Отвечают через кнопку "Ответить" в Telegram
4. Их ответы автоматически попадают в Okdesk

### Для специалистов (как Юлия):
1. Получают уведомления о новых сообщениях от клиентов в Telegram
2. Могут отвечать прямо в Okdesk или через Telegram бота
3. Клиенты автоматически получают уведомления об ответах

## 🚀 Что нужно сделать для запуска

### 1. Настроить webhook в Okdesk
```
URL: http://your-domain:8001/okdesk-webhook
События: new_comment, status_changed, assignee_changed
```

### 2. Запустить webhook сервер
```bash
# Локально
python -m uvicorn services.webhook_server:app --host 0.0.0.0 --port 8001

# Или через Docker
docker-compose up -d
```

### 3. Настроить маппинг специалистов
Создать файл `database/employee_mapping.json` с соответствием ID Okdesk ↔ Telegram ID

### 4. Протестировать
```bash
python test_comment_sync.py
```
