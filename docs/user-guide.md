# Руководство пользователя

## Начало работы

### Запуск бота

1. Найдите бота в Telegram по имени или ссылке
2. Нажмите кнопку "Запустить" или отправьте команду `/start`
3. Выберите тип регистрации

### Регистрация

#### Физическое лицо

1. Нажмите "Физическое лицо"
2. Введите ваше полное имя (Фамилия Имя Отчество)
3. Поделитесь номером телефона через кнопку
4. Дождитесь подтверждения регистрации

#### Юридическое лицо

1. Нажмите "Юридическое лицо" 
2. Введите ваше полное имя (Фамилия Имя Отчество)
3. Поделитесь номером телефона через кнопку
4. Введите вашу должность
5. Введите ИНН компании (10 цифр)
6. Дождитесь подтверждения регистрации

> **Примечание:** При регистрации юридического лица бот автоматически найдет вашу компанию по ИНН и привяжет ваш профиль к ней.

## Основные функции

### Главное меню

После регистрации вам доступно главное меню с функциями:

- **Создать заявку** - создание новой заявки в системе
- **Мои заявки** - просмотр ваших заявок
- **Профиль** - информация о вашем профиле

### Создание заявки

1. В главном меню нажмите "Создать заявку"
2. Введите подробное описание проблемы
3. Заявка будет автоматически создана в системе Okdesk
4. Вы получите номер заявки для отслеживания

**Советы по описанию заявки:**
- Опишите проблему максимально подробно
- Укажите, когда проблема началась
- Добавьте информацию о том, что вы уже пробовали
- Укажите, как проблема влияет на работу

### Просмотр заявок

1. В главном меню нажмите "Мои заявки"
2. Вы увидите список ваших заявок со статусами
3. Для возврата в меню нажмите "Назад в меню"

### Отслеживание статусов

Бот автоматически отслеживает изменения в ваших заявках и уведомляет вас о:

- ✅ Принятии заявки в работу
- 🔄 Изменении статуса заявки
- 💬 Новых комментариях от специалистов
- ✅ Закрытии заявки

## Команды бота

### Основные команды

- `/start` - начать работу с ботом / перерегистрация
- `/menu` - вызов главного меню
- `/profile` - просмотр профиля
- `/help` - справка по использованию

### Навигация

В любом разделе бота доступны кнопки:
- "Назад в меню" - возврат в главное меню
- "Отмена" - отмена текущего действия

## Решение проблем

### Частые вопросы

**Q: Бот не отвечает на команды**
A: Попробуйте отправить `/start` для перезапуска бота

**Q: Не могу зарегистрироваться как юридическое лицо**
A: Проверьте правильность ввода ИНН (должно быть 10 цифр)

**Q: Не получаю уведомления о заявках**
A: Убедитесь, что у вас включены уведомления от бота в настройках Telegram

**Q: Заявка не создается**
A: Проверьте, что вы прошли полную регистрацию. При необходимости отправьте `/start` для повторной регистрации

### Технические проблемы

**Ошибка "Пользователь не найден":**
- Отправьте `/start` для регистрации
- Убедитесь, что прошли все этапы регистрации

**Ошибка "Не удалось создать заявку":**
- Проверьте подключение к интернету
- Попробуйте позже
- Обратитесь к администратору

**Проблемы с номером телефона:**
- Используйте кнопку "Поделиться номером"
- Не вводите номер вручную

## Контакты поддержки

Если у вас возникли проблемы:

1. Попробуйте команду `/help`
2. Перезапустите бота командой `/start`
3. Обратитесь к системному администратору
4. Создайте заявку через веб-интерфейс Okdesk

## Безопасность

- Не передавайте свои данные доступа третьим лицам
- Бот запрашивает только необходимую информацию
- Ваши данные защищены и не передаются третьим лицам
- При возникновении подозрительной активности немедленно обратитесь к администратору

## Обновления

Бот регулярно обновляется. Новые функции добавляются автоматически, перезапуск не требуется.
