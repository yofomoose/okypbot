# Интеграция bot_model

## Обзор

В проект успешно интегрирована модель машинного обучения из папки `bot_model/`. Это KNeighborsClassifier модель с 384-мерными векторами признаков, обученная на 19,366 примерах и способная классифицировать заявки по 90+ детализированным категориям.

## Архитектура интеграции

### Компоненты

1. **`ml/bot_model_adapter.py`** - Адаптер для работы с моделью
   - Загрузка classifier.pkl, label_encoder.pkl и metadata.json
   - Предсказание категорий с уверенностью
   - Управление состоянием модели

2. **`ml/text_vectorizer.py`** - Векторизация текста
   - Использует sentence-transformers/all-MiniLM-L6-v2
   - Преобразует текст в 384-мерные векторы
   - Предобработка и нормализация текста

3. **Обновленный `ml/classifier.py`** - Главный классификатор
   - Приоритет bot_model над другими моделями
   - Fallback на LightGBM и базовый KNN
   - Интегрированное кеширование

4. **`handlers/bot_model_handlers.py`** - Новые команды
   - `/bot_model` - информация о модели
   - `/test_bot_model` - тестирование на примерах
   - Админские callback-обработчики

## Структура файлов bot_model


## Характеристики модели

- **Тип**: KNeighborsClassifier (n_neighbors=5)
- **Размерность признаков**: 384
- **Обучающих примеров**: 19,366
- **Категорий**: 90+ детализированных категорий
- **Оптимизирована для**: Обратной связи в реальном времени
- **Стратегия обновления**: Инкрементальное добавление

## Приоритет моделей

1. **bot_model** (приоритет) - если загружена и доступна
2. **LightGBM** - если bot_model недоступна
3. **KNN базовый** - fallback вариант
4. **Ключевые слова** - последний fallback

## API интеграции

### Основные методы

```python
from ml.bot_model_adapter import BotModelAdapter
from ml.text_vectorizer import text_vectorizer

# Загрузка модели
adapter = BotModelAdapter()
adapter.load_model()

# Векторизация текста
vector = text_vectorizer.vectorize("Компьютер не включается")

# Предсказание
features = vector.reshape(1, -1)
category, confidence = adapter.predict(features)
```

### Интеграция с ML сервисом

```python
from services.ml_service import ml_service

# Инициализация (автоматически загружает bot_model)
await ml_service.initialize()

# Классификация (автоматически использует bot_model)
result = await ml_service.classify_issue(text, user_id)
```


## Troubleshooting

### Проблемы загрузки

1. **Модель не загружается**
   - Проверьте наличие всех файлов в `bot_model/`
   - Убедитесь в корректности путей
   - Проверьте права доступа к файлам

2. **Ошибка векторизации**
   - Проверьте подключение к интернету (для первой загрузки sentence-transformers)
   - Убедитесь в наличии свободной памяти
   - Проверьте версию sentence-transformers

3. **Неправильные предсказания**
   - Проверьте размерность векторов (должна быть 384)
   - Убедитесь в корректности предобработки текста
   - Проверьте соответствие label_encoder и classifier

### Логирование

Все операции логируются с префиксом компонента:
