# Machine Learning Integration

## Обзор

В ветке `feature/ml-classification` добавлен функционал машинного обучения для автоматической классификации заявок. Система может анализировать текст заявки и определять её категорию с указанием уверенности.

## Возможности

### 🤖 Автоматическая классификация
- Анализ текста заявки с использованием ML алгоритмов
- Определение категории с указанием уверенности (0-100%)
- Рекомендации по улучшению описания заявки

### 📊 Обучение модели
- Возможность добавления новых примеров через обратную связь
- Автоматическое переобучение модели на новых данных
- Сохранение истории классификаций

### 📈 Аналитика
- Статистика использования классификатора
- Распределение заявок по категориям
- Средняя уверенность классификации

## Архитектура

### Компоненты

1. **`ml/classifier.py`** - Основной классификатор
   - Загрузка и сохранение модели
   - ML классификация с использованием scikit-learn
   - Fallback на базовую классификацию по ключевым словам

2. **`services/ml_service.py`** - Сервис ML
   - Управление классификатором
   - История классификаций
   - Статистика и аналитика

3. **`handlers/ml_handlers.py`** - Обработчики команд
   - Команда `/classify` для классификации текста
   - Обратная связь пользователей
   - Просмотр статистики

### Интеграция

ML функционал интегрирован в существующий бот:

- **Создание заявок**: Автоматическая классификация при создании
- **Главное меню**: Кнопка "🤖 Классификатор"
- **Обратная связь**: Улучшение модели через пользовательские данные

## Установка и настройка

### 1. Зависимости

```bash
pip install scikit-learn numpy joblib nltk
```

Или использовать обновленный `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 2. Инициализация

ML сервис автоматически инициализируется при запуске бота:

```python
# В main.py
from services.ml_service import ml_service
await ml_service.initialize()
```

### 3. Базовая модель

При первом запуске создается базовая модель с примерами:

- Проблемы с доступом
- Ошибки в работе системы  
- Техническая поддержка
- Консультация
- Запрос на изменение
- Жалоба
- Предложение
- Другое

## Использование

### Команды

- `/classify` - Классификация произвольного текста
- Кнопка "🤖 Классификатор" в главном меню

### Процесс классификации

1. Пользователь отправляет текст заявки
2. Система анализирует текст
3. Возвращает:
   - Предполагаемую категорию
   - Уверенность (в процентах)
   - Рекомендации по улучшению

### Обратная связь

После классификации пользователь может:
- ✅ Подтвердить правильность
- ❌ Указать корректную категорию
- 📊 Посмотреть статистику

## ML Алгоритм

### Обработка текста

1. **Предобработка**:
   - Удаление лишних пробелов
   - Нормализация символов
   - Приведение к нижнему регистру

2. **Векторизация**:
   - TF-IDF с n-граммами (1-2)
   - Максимум 1000 признаков

3. **Классификация**:
   - Логистическая регрессия
   - Fallback на ключевые слова

### Базовая классификация

Если ML недоступен, используется классификация по ключевым словам:

```python
keywords = {
    "Проблемы с доступом": ["пароль", "войти", "доступ"],
    "Ошибки в работе системы": ["ошибка", "не работает", "баг"],
    # ...
}
```

## API сервиса

### Основные методы

```python
# Инициализация
await ml_service.initialize()

# Классификация
result = await ml_service.classify_issue(text, user_id)

# Обратная связь
await ml_service.add_feedback(text, correct_category, user_id)

# Переобучение
await ml_service.retrain_model()

# Статистика
stats = ml_service.get_statistics()
```

### Результат классификации

```python
{
    'category': str,      # Предполагаемая категория
    'confidence': float,  # Уверенность (0.0-1.0)
    'recommendations': List[str],  # Рекомендации
    'success': bool       # Успешность операции
}
```

## Troubleshooting

### Распространенные проблемы

1. **ML библиотеки не установлены**
   ```bash
   pip install scikit-learn numpy joblib
   ```

2. **Ошибка инициализации модели**
   - Проверить права доступа к папке `ml/models/`
   - Удалить поврежденную модель для пересоздания

3. **Низкая точность классификации**
   - Добавить больше примеров через обратную связь
   - Запустить переобучение модели

### Диагностика

```python
# Проверка статуса ML
stats = ml_service.get_statistics()
print(stats['service_status'])
print(stats['classifier']['is_trained'])
```
