# Настройка сопоставления сотрудников OkDesk и пользователей Telegram

## Введение

Система сопоставления позволяет связывать ID сотрудников в OkDesk с ID пользователей в Telegram. Это необходимо для правильной маршрутизации уведомлений и комментариев между системами.

## Как это работает

1. Когда приходит комментарий от клиента через OkDesk, система находит специалиста, ответственного за заявку
2. По ID специалиста в OkDesk система определяет его Telegram ID из настроенных сопоставлений
3. Бот отправляет уведомление напрямую этому специалисту в Telegram
4. Если сопоставление не найдено, используется ID специалиста по умолчанию

## Управление сопоставлениями

Для управления сопоставлениями есть два способа:

### 1. Через бота (для администраторов)

Администраторы бота могут управлять сопоставлениями с помощью команды `/employee_mapping`. Эта команда предоставляет доступ к следующим функциям:

- Просмотр всех сопоставлений
- Добавление нового сопоставления
- Удаление существующего сопоставления
- Установка ID сотрудника OkDesk по умолчанию

### 2. Через скрипт командной строки

Скрипт `scripts/employee_mapping.py` позволяет управлять сопоставлениями через командную строку:

```bash
# Просмотр справки
python -m scripts.employee_mapping --help

# Список всех сопоставлений
python -m scripts.employee_mapping list

# Добавление сопоставления
python -m scripts.employee_mapping add <okdesk_id> <telegram_id>

# Удаление сопоставления
python -m scripts.employee_mapping remove <okdesk_id>

# Установка ID сотрудника по умолчанию
python -m scripts.employee_mapping default <okdesk_id>

# Запуск интерактивного меню
python -m scripts.employee_mapping menu
```

## Файл сопоставлений

Сопоставления хранятся в файле `database/employee_mapping.json`. Формат файла:

```json
{
  "mappings": {
    "<okdesk_id_1>": <telegram_id_1>,
    "<okdesk_id_2>": <telegram_id_2>,
    ...
  },
  "default_employee_id": "<okdesk_id>"
}
```

## Как определить ID сотрудника в OkDesk

1. Зайдите в OkDesk
2. Перейдите к профилю сотрудника
3. ID сотрудника можно увидеть в URL адресе страницы (например, `.../employees/12345`)

## Как определить ID пользователя в Telegram

1. Попросите пользователя отправить сообщение боту @userinfobot
2. Бот вернет ID пользователя и другую информацию
3. Также администратор может использовать команду `/whoami` в боте

## Рекомендации

- Настройте сопоставления для всех сотрудников, которые работают с заявками
- Обязательно установите ID сотрудника по умолчанию, чтобы уведомления не терялись
- Регулярно проверяйте актуальность сопоставлений
- При добавлении новых сотрудников не забудьте добавить их в систему сопоставлений
