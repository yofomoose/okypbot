# Участие в разработке

Мы приветствуем вклад в развитие проекта! Вот как вы можете помочь:

## 🚀 Быстрый старт

1. **Форкните репозиторий**
2. **Создайте ветку для новой функции**:
   ```bash
   git checkout -b feature/new-feature
   ```
3. **Внесите изменения**
4. **Зафиксируйте изменения**:
   ```bash
   git commit -m "Добавить новую функцию"
   ```
5. **Отправьте изменения**:
   ```bash
   git push origin feature/new-feature
   ```
6. **Создайте Pull Request**

## 📋 Правила разработки

### Код

- Используйте Python 3.9+
- Следуйте PEP 8
- Добавляйте типизацию (type hints)
- Покрывайте код комментариями
- Используйте docstrings для функций и классов

### Коммиты

Используйте конвенцию [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: добавить новую функцию
fix: исправить ошибку
docs: обновить документацию
style: форматирование кода
refactor: рефакторинг
test: добавить тесты
chore: обновить зависимости
```

### Ветки

- `main` - стабильная версия
- `develop` - ветка разработки
- `feature/*` - новые функции
- `fix/*` - исправления ошибок
- `hotfix/*` - критические исправления

## 🧪 Тестирование

Перед отправкой PR убедитесь, что:

1. **Код работает без ошибок**:
   ```bash
   python main.py
   ```

2. **Проверьте форматирование**:
   ```bash
   black . --check
   flake8 .
   ```

3. **Проверьте типы**:
   ```bash
   mypy .
   ```

## 📖 Документация

- Обновляйте README.md при добавлении новых функций
- Добавляйте комментарии к сложным участкам кода
- Документируйте новые API методы
- Обновляйте CHANGELOG.md

## 🐛 Сообщения об ошибках

При создании Issue укажите:

- Версию Python
- Версию библиотек (requirements.txt)
- Шаги для воспроизведения
- Ожидаемое поведение
- Фактическое поведение
- Логи ошибок

## 💡 Предложения функций

Перед реализацией новой функции:

1. Создайте Issue с описанием
2. Дождитесь обсуждения
3. Получите одобрение от maintainer-ов
4. Приступайте к разработке

## 🔧 Настройка окружения разработки

1. **Клонируйте репозиторий**:
   ```bash
   git clone <your-fork>
   cd okypbot
   ```

2. **Создайте виртуальное окружение**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   ```

3. **Установите зависимости разработки**:
   ```bash
   pip install -r requirements.txt
   pip install -r requirements-dev.txt  # если есть
   ```

4. **Настройте pre-commit hooks**:
   ```bash
   pre-commit install
   ```
