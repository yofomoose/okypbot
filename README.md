# OkypBot - Telegram Bot для интеграции с Okdesk CRM

Telegram бот для автоматизации работы с системой Okdesk CRM. Бот позволяет пользователям регистрироваться, создавать заявки и отслеживать их статус прямо из Telegram.

## 🚀 Основные возможности

- **Регистрация пользователей**: Поддержка физических и юридических лиц
- **Интеграция с Okdesk**: Автоматическое создание контактов и компаний
- **Создание заявок**: Создание заявок в Okdesk через Telegram
- **Отслеживание статуса**: Мониторинг статуса заявок в реальном времени
- **Поиск по ИНН**: Автоматический поиск компаний по ИНН
- **Привязка к компаниям**: Автоматическая привязка сотрудников к компаниям
- **Просмотр заявок**: Просмотр списка заявок пользователя

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd okypbot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните переменные окружения в файле `.env`:
   - `BOT_TOKEN` - токен бота от @BotFather
   - `OKDESK_API_TOKEN` - API токен из настроек Okdesk
   - `OKDESK_BASE_URL` - URL вашего аккаунта Okdesk

## Настройка Okdesk API

1. Войдите в ваш аккаунт Okdesk
2. Перейдите в "Настройки" → "API"
3. Создайте новый API ключ
4. Скопируйте токен в файл `.env`

## Запуск

```bash
python main.py
```

## Регистрация пользователей

Бот поддерживает два типа пользователей:

### 👤 Физические лица
Требуемые данные:
- ФИО (Фамилия Имя Отчество)  
- Номер телефона

### 🏢 Юридические лица  
Требуемые данные:
- ФИО (Фамилия Имя Отчество)
- Номер телефона
- Должность в компании
- ИНН компании (10 или 12 цифр)

### Процесс регистрации

1. Пользователь выбирает тип (физ./юр. лицо)
2. Вводит ФИО с автоматическим форматированием
3. Указывает номер телефона с валидацией
4. Для юр. лиц: должность и ИНН компании
5. Подтверждает данные
6. Система создает контакт в Okdesk
7. Для юр. лиц: ищет/создает компанию по ИНН
8. Показывается инструкция по работе с ботом

### Валидация данных

- **Телефон**: поддержка форматов +7, 8, 7 + 10 цифр
- **ИНН**: 10 или 12 цифр с проверкой контрольной суммы
- **ФИО**: минимум 2 слова, только буквы и допустимые символы

## Команды бота

- `/start` - Главное меню / Начало работы
- `/help` - Справка по командам  
- `/register` - Регистрация в системе
- `/profile` - Просмотр профиля пользователя
- `/issues` - Просмотр заявок
- `/create_issue` - Создание новой заявки
- `/companies` - Список компаний
- `/contacts` - Список контактов

## API методы Okdesk

Бот использует следующие методы Okdesk API:

### Заявки
- `GET /api/v1/issues` - получение списка заявок
- `POST /api/v1/issues` - создание заявки
- `GET /api/v1/issues/{id}` - информация о заявке
- `PATCH /api/v1/issues/{id}/status` - смена статуса
- `POST /api/v1/issues/{id}/comments` - добавление комментария

### Компании
- `GET /api/v1/companies` - список компаний
- `GET /api/v1/companies/search` - поиск компаний
- `POST /api/v1/companies` - создание компании

### Контакты
- `GET /api/v1/contacts` - список контактов
- `GET /api/v1/contacts/search` - поиск контактов
- `POST /api/v1/contacts` - создание контакта

### Справочники
- `GET /api/v1/issue_types` - типы заявок
- `GET /api/v1/issue_priorities` - приоритеты заявок
- `GET /api/v1/issue_statuses` - статусы заявок
- `GET /api/v1/employees` - сотрудники
