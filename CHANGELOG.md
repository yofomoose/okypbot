# Changelog

Все важные изменения в проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-08-16

### Добавлено
- Первый релиз бота
- Регистрация физических и юридических лиц
- Интеграция с Okdesk API
- Автоматическое создание контактов в Okdesk
- Поиск компаний по ИНН
- Автоматическая привязка сотрудников к компаниям
- Создание заявок через Telegram
- Мониторинг статуса заявок
- Обновление существующих контактов при регистрации
- Система валидации данных
- Логирование всех операций

### Технические особенности
- Использование aiogram 3.4.1
- Асинхронная архитектура
- Модульная структура проекта
- Обработка ошибок API
- Конфигурация через переменные окружения

### Поддерживаемые функции
- `/start` - начало работы и регистрация
- Создание заявок с автоматической привязкой к контактам
- Просмотр списка заявок пользователя
- Упрощенное главное меню
- Кнопка "Назад в меню" во всех разделах

### Исправлено
- Удалено поле `tg_username` из API запросов (вызывало ошибки валидации)
- Убрано автоматическое создание заявок при регистрации
- Добавлен обработчик кнопки отправки номера телефона
- Исправлена привязка заявок к пользователям
- Убран показ ID компании в подтверждении регистрации
- Упрощено главное меню (убраны кнопки поиска и настроек)
- Добавлены кнопки возврата в меню во всех разделах
- Исправлены ошибки регистрации физических лиц
- Реализовано обновление существующих контактов с привязкой к компаниям

### Технические детали
- API клиент с полной поддержкой Okdesk API
- Поиск компаний через параметры API
- Обновление контактов методом PUT
- Логирование всех API операций
- Обработка существующих и новых контактов

## [0.9.0] - 2025-08-15

### Добавлено
- Базовая структура проекта
- Настройка конфигурации
- Создание обработчиков команд

### В разработке
- Интеграция с Okdesk API
- Система регистрации пользователей

## Типы изменений

- `Добавлено` для новых функций
- `Изменено` для изменений в существующих функциях  
- `Устарело` для функций, которые скоро будут удалены
- `Удалено` для удаленных функций
- `Исправлено` для исправлений ошибок
- `Безопасность` для исправлений уязвимостей
