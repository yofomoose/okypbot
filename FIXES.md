# Исправления проблем регистрации

## Проблема с ошибкой 422 при регистрации юридических лиц

### Причина ошибки:
```
API Error 422: {"errors":{"contact_company_eq_passed_company":["владелец данного ключа не имеет доступа к переданной компании"]}}
```

Эта ошибка возникает, когда пытаемся создать контакт с привязкой к компании, к которой у API ключа нет доступа.

### Примененные исправления:

1. **Разделение создания компании и контакта:**
   - Сначала создаем/ищем компанию по ИНН
   - Затем создаем контакт БЕЗ автоматической привязки к компании
   - Привязку к компании можно сделать вручную в интерфейсе Okdesk

2. **Улучшенная обработка ошибок:**
   - Добавлены специфичные сообщения для ошибок 422 и 401
   - Информативные сообщения для пользователя
   - Логирование ошибок для отладки

3. **Безопасный режим регистрации:**
   - Если не удается создать компанию - продолжаем без неё
   - Если не удается привязать к компании - создаем контакт как физлицо
   - Сохраняем информацию о компании в локальной БД для последующей привязки

### Файлы изменены:
- `handlers/registration.py` - улучшена логика регистрации юрлиц
- `api/okdesk_api.py` - добавлена обработка ошибок создания компаний

### Рекомендации:
1. Проверьте права доступа API ключа в настройках Okdesk
2. При необходимости привяжите контакты к компаниям вручную в интерфейсе Okdesk
3. Рассмотрите возможность получения расширенных прав для API ключа
